# Lore snapshot

Copied from the claude.ai project "Tales of Words" on 21 Oct 2026. **The claude.ai project is the canonical source**; these files are a read-only snapshot for writing event and content text. If the lore changes there, refresh this folder.

- `world/`: faiths and orders, bestiary, peoples and cultures, items and relics, factions, countries and politics. The magic system is in `docs/spec/magic-system.md`.
- `characters/`: the three sisters (Seffira, Viskan, Lina) and their party roles.

Names written as `{{id}}` are wiki variables (placeholder names that can be renamed). Event text in game content stays placeholder until the wiki defines it.
